# UCU Behavior Lab

[English](https://mhcardozo.github.io/ucu-behavioral-lab/) · [Español](https://mhcardozo.github.io/ucu-behavioral-lab/es.html)

Bilingual website for behavioral and experimental economics at Universidad Católica del Uruguay in Montevideo.

Edit `index.html` for English and `es.html` for Spanish. Both pages use `lab.css` and `game.js`. Add researchers and publications to both language versions. Open either HTML file in a browser to preview changes.

GitHub Pages publishes the repository root from the `main` branch.
